# test_distributed_systems

Proyecto de práctica de **Git Flow**. Cada paso del flujo deja un cambio en este archivo y se integra mediante **Pull Request**.

## Ramas base

### `main`
Rama de producción: solo código estable / releases.

### `develop`
Rama de integración continua. Aquí aterrizan las features antes de un release.

## Flujos

### Feature (`feature/*`)
- Se crea desde `develop`
- Se integra a `develop` mediante PR
- Ejemplo: documentación del flujo de feature en este README
